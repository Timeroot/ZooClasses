Nonuniform ⊕L. The class of decision problems solvable by a {lang:⊕L} machine (parity logspace — answering "yes" iff the number of accepting paths of a nondeterministic logspace machine is odd) that additionally receives a polynomial-length classical advice string depending only on the input length.
