Parity L. Has the same relation to L as ⊕P does to P: the class of decision problems solvable by an NL machine such that the answer is "yes" iff the number of accepting paths is odd.

Contains {lang:SL} {ref:kw93}.

Solving a linear system over Z_2 is ⊕L-complete {ref:dam90}. Simulating stabilizer circuits is ⊕L-complete {ref:ag04}.

⊕L^{⊕L} = ⊕L {ref:bdh92} {ref:hrv00}.
