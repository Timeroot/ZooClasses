Nonuniform FNL. The class of function problems solvable by an {lang:FNL} machine (nondeterministic logspace function computation) that additionally receives a polynomial-length classical advice string depending only on the input length.

The advice allows the machine to "hard-code" information about each input size, just as {lang:P/poly} extends P with nonuniform advice. Contained in #L/poly.
