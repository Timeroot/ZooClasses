FewP with Flexible Acceptance Mechanism. Also called FewPaths. The class of decision problems solvable by an NP machine such that: (1) the number of accepting paths a is bounded by a polynomial in the input size; (2) for some polynomial-time predicate Q, Q(x,a) is true iff the answer is "yes."

Defined in {ref:ch89}. Contains {lang:FewP}, and is contained in P^{FewP} {ref:kob89} and in {lang:SPP} {ref:ffk94}.
