Bounded-Error Probabilistic Logspace. The class of decision problems solvable by a probabilistic Turing machine using O(log n) space with error probability at most 1/3 on every input. The machine must halt on every input and every random tape setting. The random bits are read once (one-way tape), unlike {lang:BP•L}, which allows two-way access to randomness.

Contained in {lang:SC} {ref:nis92}, {lang:PL}, BP•L, ZP•L {ref:nis93}, {lang:DET} {ref:coo85}, {lang:NC^2}, and P {ref:bcp83}.
