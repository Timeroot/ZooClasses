Primitive Recursive Functions. The class of functions definable by recursively building up arithmetic operations: addition, multiplication, exponentiation, tetration, etc. What is NOT allowed is to diagonalize over a whole series of such functions to produce an even faster-growing one.

The Ackermann function (proposed 1928) is an example of a recursive function that is NOT primitive recursive, showing PR ⊊ R.

Alternatively, PR is exactly the class computable by programs in an idealized ALGOL-like language where only definite loops are allowed (loops where the number of iterations is specified before the loop begins).

Strictly contains {lang:ELEMENTARY}. Does not have complete problems under elementary reductions (unlike {lang:TOWER} and {lang:Ack}).
