Zero-Error Probabilistic L with Two-Way Access to Randomness. Has the same relationship to {lang:BP•L} as ZPP has to BPP. Logspace polynomial-time Turing machine with a read-only randomness tape such that on input x:
1. With high probability, the machine correctly outputs whether x is in the language.
2. When the machine outputs "I don't know," it never outputs a wrong answer.

See {lang:BP•L} for context.
