Second-Order Logic. An extension of First-Order Logic with quantification over second-order variables (which represent sets or relations of arbitrary arity).

Formulae can be put into prenex normal form: all second-order quantifiers first, followed by a first-order formula. SO is equal to {lang:PH} (the polynomial hierarchy) {ref:imm98}. More precisely, SO formulae in prenex normal form with k alternating second-order quantifiers correspond to the k-th level of PH. SO with only existential second-order quantification equals Σ_1 = NP {ref:fag74}, and with only universal quantification equals Π_1 = coNP.

Variants include SO(Horn), SO(Krom), SO[LFP], and SO[TC]. See also {lang:HO}.
