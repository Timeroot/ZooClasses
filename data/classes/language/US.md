Unique Polynomial-Time. The class of decision problems solvable by an NP machine such that the answer is "yes" if and only if exactly one computation path accepts.

In contrast to {lang:UP}, a US machine can have more than one accepting path — that just means the input is not in the language.

Defined in {ref:bg82}. Contains coNP.
