Parity P. The class of decision problems solvable by an NP machine such that:
1. If the answer is "yes," the number of accepting paths is odd.
2. If the answer is "no," the number of accepting paths is even.

Defined in {ref:pz83}.

Contains Graph Isomorphism; indeed, Graph Isomorphism is low for ⊕P {ref:ak02}. Contains {lang:FewP} {ref:ch89}.

There exists an oracle where P = ⊕P but P ≠ NP (and NP = EXP) {ref:bbf98}.

Equals Mod_{2^m}P for every positive integer m.
