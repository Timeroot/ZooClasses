Steve's Class (named in honor of Stephen Cook). The class of decision problems solvable by a Turing machine that simultaneously uses polynomial time and polylogarithmic space.

Note that SC might be smaller than P ∩ polyL, since for polyL it only requires a single polylogarithmic-space algorithm, while SC requires one algorithm that is both simultaneously polynomial-time and polylogarithmic-space.

Deterministic context-free languages (DCFLs) can be recognized in SC {ref:coo79}. Contains {lang:RL} and {lang:BPL} {ref:nis92}. Equals DTISP(poly, polylog).
