---
name: P-Sel
related:
  - NP
  - R
---
The class of decision problems for which there's a polynomial-time algorithm with the following property: whenever given two instances, one a "yes" instance and one a "no" instance, the algorithm can always correctly identify which is the "yes" instance. (It acts as a "selector" between two candidates.)

Defined in {ref:sel79}, where it was also shown that if NP ⊆ P-Sel then P = NP.

There exist P-selective sets that are not recursive (i.e. not in R).
