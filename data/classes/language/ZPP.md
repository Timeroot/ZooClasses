Zero-Error Probabilistic Polynomial-Time. Defined as RP ∩ coRP. Equivalently, the class of problems solvable by randomized algorithms that always return the correct answer and whose expected running time is polynomial {ref:gil77}.

Contains primality testing {ref:ss77} {ref:ah87}, though primality is now in P {ref:aks02}.

Unlike BPP and RP, it is not known whether ZPP = P requires proving superpolynomial circuit lower bounds {ref:ki02}.
