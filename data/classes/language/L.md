Logarithmic Space. The class of decision problems solvable by a Turing machine using O(log n) space (not counting the input tape).

Contains {lang:NC^1} {ref:bor77}, and is contained in {lang:NL} and {lang:P}. Also contained in L/poly, {lang:SL}, {lang:RL}, and Mod_kL.

Remarkably, L = {lang:SL}: undirected graph connectivity is solvable in deterministic logspace {ref:rei04}.

L equals FO(dtc), the class of first-order expressible queries with a deterministic transitive closure {ref:imm83}.
