Wide PP. The class of decision problems solvable by an NP machine such that:
1. If the answer is "no," the number of accepting paths equals the number of rejecting paths.
2. If the answer is "yes," their difference equals a function f(x) computable in polynomial time (FP).

Defined in {ref:ffk94}.

Contained in C_=P ∩ coC_=P, and in {lang:AWPP}. Contains {lang:SPP} and {lang:LWPP}.
