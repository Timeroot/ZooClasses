Logspace-Bounded Few. The class of decision problems solvable by an NL machine such that:
1. The number of accepting paths on input x is some value f(x).
2. The answer is "yes" if and only if R(x, f(x)) = 1, where R is a predicate computable in L.

Defined in {ref:bdh92}, where it was also shown that LogFew is contained in Mod_kL for all k > 1.
