Total Function Nondeterministic Polynomial time. Relations that can be checked by deterministic polynomial time machine. In other words, the class of function problems of the following form: Given an input x and a polynomial-time predicate F(x,y), output any y satisfying F(x,y) -- where such a y is promised to exist for any x. Morally, this is often viewed as the equivalent of {lang:NP}∩{lang:coNP}.
