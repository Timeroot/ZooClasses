Total Function NP. The class of function problems of the following form: given an input x and a polynomial-time predicate F(x,y), output any y satisfying F(x,y), where such a y is promised to exist.

Can be viewed as the functional analogue of NP ∩ coNP. Defined in {ref:mp91}.

Contained in {lang:FNP}. Subclasses include {lang:PPA}, {lang:PPP}, and {lang:PLS}.
