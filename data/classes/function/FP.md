Function Polynomial-Time. The class of functions computable in polynomial time by a Turing machine. Can be defined as the class of FNP problems for which there exists a polynomial-time algorithm that outputs any valid y (possibly not unique).

FP = FNP iff P = NP. If FP^NP = FP^{NP[log]}, then P = NP {ref:kre88}.
