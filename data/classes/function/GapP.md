Gap Polynomial-Time. The class of functions f(x) such that for some NP machine, f(x) equals the number of accepting paths minus the number of rejecting paths. Equivalently, the closure of the #P functions under subtraction.

Defined in {ref:ffk94} and independently {ref:gup95}.
