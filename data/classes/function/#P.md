Sharp-P or Number-P. The class of function problems of the form "compute f(x)," where f is the number of accepting paths of an NP machine.

The canonical #P-complete problem is #SAT. Defined in {ref:val79}, where it was also shown that #Perfect Matching (equivalently, Permanent) is #P-complete. What makes this surprising is that the associated decision problem (Perfect Matching) is in P.

PH ⊆ P^{#P} {ref:tod89}; a single query to #P suffices.

Any function in #P can be approximated within a polynomial factor in BPP^NP {ref:sto85}.
