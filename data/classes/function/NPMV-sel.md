NPMV-Selective Sets. The class of function problems f ∈ NPMV for which there exists a polynomial-time computable selector: given any two inputs x, y, the selector outputs either x or y such that if one of f(x), f(y) is defined then the selected element's value is defined.

This is the NPMV analogue of {lang:P-Sel}: instead of a P selector distinguishing "yes" from "no" instances, we have a polynomial-time selector on nondeterministic multivalued functions.
