NP with Few Witnesses. The class of decision problems solvable by an NP machine such that: (1) if the answer is "no," all computation paths reject; (2) if the answer is "yes," the number of accepting paths is bounded by a polynomial in the input size.

Defined in {ref:ar88}. Contained in ⊕P {ref:ch89}. There exist oracles relative to which P, UP, FewP, and NP are all distinct {ref:rub88}. Contained in {lang:Few}.
