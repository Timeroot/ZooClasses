Gap Logspace. The class of functions f: {0,1}* → ℤ such that for some nondeterministic logspace Turing machine M, f(x) equals the number of accepting computation paths of M on input x minus the number of rejecting computation paths. Equivalently, GapL is the closure of the #L functions under subtraction.

The determinant of integer matrices is GapL-complete {ref:vin91} {ref:dam91} {ref:tod91}. See also the decision class {lang:DET}.
