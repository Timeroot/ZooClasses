Function BQP. The class of function problems solvable by a polynomial-time quantum algorithm with bounded error: given an input x and a polynomial-time verifiable predicate F(x,y), if there exists a y satisfying F(x,y), output any such y with probability ≥ 2/3; otherwise output 'no' with probability ≥ 2/3.

The quantum analogue of {lang:FBPP}, where the computing machine is a polynomial-time quantum computer (BQP machine). Contains FP and is contained in FNP.
