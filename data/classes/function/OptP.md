Optimum Polynomial-Time. The class of functions computable by taking the maximum (or minimum) output value over all accepting paths of an NP machine. OptP[f(n)] restricts the output size to f(n) bits.

Defined in {ref:kre88}. Contrast with {lang:FNP}.

MaxSAT (number of satisfied clauses), Maximum Clique size, and Chromatic Number are OptP[log n]-complete.
