NPSV-Selective Sets. The class of single-valued functions f ∈ NPSV for which there exists a polynomial-time computable selector: given any two inputs x, y, the selector outputs either x or y such that if one of f(x), f(y) is defined, the selected element's value is defined.

The single-valued analogue of {lang:NPMV-sel}: the same selector condition but restricted to nondeterministic single-valued (NPSV) functions.
