Sharp-L. Has the same relation to L as {lang:#P} does to P. The class of functions counting the number of accepting paths of a logspace (NL) machine.

Contained in the function class version of DET {ref:aj93}. The determinant is GapL-complete (see {lang:GapL}), where GapL consists of functions that are the difference of two #L functions.
