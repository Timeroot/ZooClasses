Fixed Parameter and Error Randomized Time. A parameterized class. FPERT is the class of decision problems of the form (x, k1, k2) decidable in time f1(k1)·p(|x|) by a probabilistic Turing machine such that: (1) if yes, acceptance probability ≥ 1/2 + min(f2(k2), 1/|x|^c); (2) if no, acceptance probability ≤ 1/2.

Defined in {ref:kw15}. Contains FERT and FPT. Contained in para-NP^PP.
